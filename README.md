# Knowledge Assistant

An AI-powered knowledge assistant built with FastAPI, React, and Retrieval-Augmented Generation (RAG).

---

## Overview

Knowledge Assistant enables users to upload documents, build a searchable knowledge base, and ask natural language questions. The application retrieves relevant information from uploaded documents and generates context-aware responses using a local language model.

---

## Features

- Upload PDF documents
- Automatic text extraction
- Intelligent document chunking
- Semantic search using vector embeddings
- AI-powered question answering
- Source reference for every response
- Local-first architecture
- RESTful API
- Modern React UI

---
